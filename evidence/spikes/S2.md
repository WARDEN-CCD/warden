# Spike S2 — laptop parity: does the `lite` platform fit? (2026-10-24)

**Question (DESIGN Q4):** does the `lite` profile fit a 16 GB Windows laptop with WSL2 capped at about 10 GB?
**Answer: yes.** With every lite component running and settled, the two kind node containers use
**5.96 GiB** (median of 6 samples, 30 s apart). That leaves about 4 GiB of a 10 GiB WSL2 budget for Docker
Desktop's own overhead, the four services (about 1.2 GiB together, planned at 256–512 MiB each) and the k6 load
generator.

- Raw data: [`S2/memory-2026-10-24T132222Z.json`](S2/memory-2026-10-24T132222Z.json)
- Tool: `warden-infra/scripts/measure_memory.py` (`task measure`)

### Where kube-system's 2.4 GiB goes

| Pod | Memory |
|-----|-------:|
| kube-apiserver | **2033 MiB** |
| etcd | 106 MiB |
| kube-controller-manager | 88 MiB |
| everything else (scheduler, CoreDNS ×2, kube-proxy ×2, kindnet ×2, metrics-server) | ~150 MiB |

The API server dominates because the platform installs **96 CRDs**, and the API server keeps the OpenAPI schema
of every CRD in memory. That makes it the largest single memory cost of the platform: more than Prometheus and
Grafana combined (466 + 418 MiB).

## Bootstrap time

`task up:local` from nothing to 16/16 Synced/Healthy: **1583 s (26.4 min)** on the first run, including
pulling every image (ledger row 2, `evidence/rebuilds/rebuild-ledger.csv`). A warm rebuild is measured
separately in E6.

## Issues found and fixed during S2

| Issue | Fix |
|-------|-----|
| Host port 8080 already taken (`wslrelay`) — first `up:local` failed after 49 s (ledger row 1) | Gateway mapped to `127.0.0.1:18080/18443`; loopback-only also keeps it off the LAN |
| Kyverno Application permanently OutOfSync: the `kyverno-api` subchart renders `labels: {}` on 11 CRDs | `kyverno-api.labels` set (warden-gitops#5); diagnosed with `argocd app diff --core` |
| Runtime-injected webhook `caBundle`s would fight self-heal | Global `ignoreDifferences` + `RespectIgnoreDifferences` (warden-gitops#3) |
| Security review: service apps in `default` project; Prometheus/Grafana discovery in all namespaces; Grafana default password | `apps` AppProject, label-scoped discovery, random Grafana password from bootstrap (warden-gitops#2, warden-infra) |

## Recommendations

1. Set `memory=10GB` (minimum) or `12GB` (comfortable) under `[wsl2]` in `%USERPROFILE%\.wslconfig` on 16 GB
   laptops. `doctor.py` warns below 8 GiB.
2. Re-measure with the four services and k6 running (milestone M2) and add the rows here.
3. Possible saving: Kyverno still installs its deprecated `kyverno.io` CRDs, which Warden never uses (ADR-006).
   Dropping them would cut the CRD count and so the API server's memory. Try it once Kyverno 1.20 removes them.

# Submission presentation

- `Warden-CCD-Project-Presentation.pptx` is the editable 17-slide deck.
- `Warden-CCD-Project-Presentation.pdf` is the matching export for submission or viewing.

The editable deck is generated by `scripts/build_presentation.cjs`. From the `scripts/` directory, run `npm ci` once and
`npm run build` after editing the source. Re-export the PDF and inspect the rendered pages before replacing these files.
The Azure PostgreSQL slide remains marked as pending until a live service connection and teardown have been verified.
